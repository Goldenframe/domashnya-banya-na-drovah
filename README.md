# Веб-приложение для бронирования бани

Дипломный проект. Разработала веб-приложение для банного комплекса: посетители могут зарегистрироваться, войти в личный кабинет и забронировать время онлайн. В проекте также есть административная панель.

Я разработала клиентскую и серверную части, развернула приложение на VPS и настроила домен и HTTPS.

## Технологии

- Клиент: React, React Router, Axios и Vite. Исходный код находится в папке [client](./client).
- Сервер: Node.js и PostgreSQL. Код находится в [отдельном репозитории](https://github.com/Goldenframe/domashnya-banya-na-drovah-server).

## Запуск клиента

```bash
cd client
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Для регистрации, входа и бронирования нужен запущенный сервер с настроенной базой данных.

Команда для сборки клиента: `npm run build`.

## Архитектура клиента

Код в [client/src](./client/src) организован по Feature-Sliced Design с подходом Pages First.

- `app`: точка входа, маршрутизация и глобальные стили.
- `pages`: главная, вход, регистрация, восстановление пароля и два личных кабинета. Галерея, бронирование, интервалы и скидки находятся рядом со страницами, которые их используют.
- `widgets`: навигация для пользователя и администратора, которая используется на главной и в кабинетах.
- `features`: редактирование профиля, общее для двух кабинетов.
- `shared`: HTTP-клиент, индикатор загрузки, общие стили и утилиты.

Слои импортируют код из нижележащих слоёв. Страницы, виджет навигации и редактирование профиля экспортируют компоненты через свои `index.js`.
Чтобы подключить другой сервер, задай `VITE_API_URL` в `client/.env.local` и перезапусти Vite. Укажи адрес сервера без суффикса `/api`.
